## Project Overview
This repository contains the complete Portfolio of Evidence (PoE) for WEDE5020POE.

The project is a professional website for **Paws for Hope**, a non-profit animal rescue organisation based in Johannesburg, South Africa. The organisation rescues, rehabilitates and rehomes abandoned, abused and stray dogs and cats across Gauteng.

- **Part 1** – HTML foundation, content, navigation and project planning  
- **Part 2** – Visual design with CSS  
- **Part 3** – JavaScript functionality, form validation, interactivity and SEO  

## Website Goals and Objectives
- Increase online adoptions by 40% within 12 months
- Grow monthly donations through an easy enquiry system
- Attract new volunteers
- Build trust and brand awareness

## Key Features and Functionality

### Part 1 & 2
- 5 core pages with consistent navigation
- Semantic HTML5 structure
- Responsive-ready layout
- Clean visual design with brand colours

### Part 3 Additions
- **JavaScript interactivity**
  - Mobile menu toggle
  - Accordion on About page
  - Animal search and filter on Services page
  - Lightbox gallery for animal photos
  - Modal success messages
  - Scroll fade-in animations
- **Form validation (client-side)**
  - Enquiry form (volunteer / sponsor / adopt)
  - Contact form with subject and message
  - Real-time error messages
  - Simulated AJAX success feedback
- **Interactive map** (Leaflet + OpenStreetMap) on Contact page
- **SEO**
  - Unique title tags and meta descriptions on every page
  - Proper heading hierarchy
  - Image alt text
  - robots.txt and sitemap.xml
  - Internal linking and mobile-friendly design
